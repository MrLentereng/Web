# Foundry import/export round-trip

## Экспорт из Foundry VTT

1. Откройте нужный Actor/Item в Foundry.
2. В меню документа используйте **Export Data** (JSON).
3. Для пачки документов можно экспортировать несколько JSON и импортировать их по очереди в секции редактора.

## Импорт в этот редактор

1. Откройте нужную секцию (Actors/Items/Spells/Effects/Journal/Tables).
2. Нажмите `Import JSON`.
3. Выберите JSON одного документа или массив документов.

## Round-trip гарантия

Редактор хранит и возвращает документ целиком, включая неизвестные поля:
- `flags`
- любые дополнительные `system.*`
- `ownership` / `permission`-совместимые поля
- `img`, `folder`, `sort`, произвольные кастомные ключи

Это обеспечивается тем, что raw JSON сущности хранится и редактируется напрямую, а форменные поля патчат только конкретные пути.

## Экспорт обратно

- `Export Entity` — текущая сущность как Foundry JSON.
- `Export Project JSON` — внутренний формат проекта с версиями.
- `Export Package` — manifest + набор коллекций (`actors/items/journal/tables`) в одном JSON-пакете (для последующей zip-упаковки).
